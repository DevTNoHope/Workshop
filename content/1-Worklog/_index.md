### 🚀 Overview of the Internship & Learning Journey (Worklog)

Welcome to my worklog repository documenting my journey throughout the **First Cloud AI Journey (FCAJ)** program. This is a comprehensive, structured record documenting my learning progress, research, and cloud engineering implementations on Amazon Web Services (AWS) over **12 weeks**.

The program was executed in a **hybrid** learning model (combining remote self-study, technical syncs at the office, and participation in major community technology events like AWS Community Days). The 12-week roadmap is split into two core phases:

1. **Phase 1: Mastering AWS Infrastructure via Hands-on Labs (Weeks 1 - 7)**
   * Successfully completed 39 practical AWS labs (Labs 001 to 040, excluding Lab 12 for resource optimization).
   * Conducted in-depth research spanning fundamental services (VPC, EC2, RDS, IAM, S3) to advanced cloud architectures (CI/CD, Monitoring, Security, Cost Optimization, Container/ECS/EKS).
2. **Phase 2: Developing the Serverless ITCoach Interview Platform (Weeks 8 - 12)**
   * Planned, designed, and developed a secure, scalable 3-tier Serverless architecture.
   * Integrated core AWS services with AI APIs (OpenAI Whisper/GPT API and Amazon Polly) to build a mock-interview simulator tailored for IT students.
