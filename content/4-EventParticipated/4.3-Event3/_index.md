# Event Report: FCAJ Community Day (07/11/2026)

### 1. General Event Information
* **Event Name**: FCAJ Community Day (AWS First Cloud AI Journey)
* **Date & Time**: Saturday, July 11, 2026 (09:00 AM – 12:00 PM)
* **Location**: AWS Office, 26th Floor, Bitexco Financial Tower, District 1, Ho Chi Minh City
* **Role**: Attendee

---

### 2. Key Technology Topics Shared

#### Topic 1: Cloud Architect Grand Finale
* **Speakers/Teams**: Team KLKAT and Team Ngu Dai Hiep
* A highly anticipated showdown between the two top teams of the Cloud Architect program, competing to solve real-world architectural design and optimization scenarios under judges' evaluation.
* Concurrently, an interactive AWS knowledge mini quiz was held for the two finalist teams, while the audience in the hall eagerly watched and cheered.

#### Topic 2: Securing Your Web Apps With AWS Security Agent
* **Speaker**: Thinh Nguyen (DevSecOps/Cloud Engineer)
* Explored the importance of web application security in modern cloud environments and introduced the AWS Security Agent alongside its core principles.
* Discussed configuring security policies, continuous monitoring, vulnerability detection, and DevSecOps best practices to integrate automated security checks into CI/CD pipelines.

#### Topic 3: SLA and Monitoring - From SLA to Monitoring what really matters
* **Speaker**: Nguyen Huynh Son
* Clarified SLA (Service Level Agreement), SLO (Service Level Objective), and SLI (Service Level Indicator) in system operations.
* Provided guidance on constructing effective monitoring systems based on metrics reflecting direct end-user experience (such as HTTP 5xx error rates and API latency) instead of simply collecting raw logs.

#### Topic 4: Inside The Exam: AWS Cloud Practitioner
* **Speaker**: Ngo Le Tan Huy
* Provided an overview of the exam structure and key domains covered in the AWS Cloud Practitioner certification.
* Shared a detailed learning roadmap, recommended study guides, mock exam resources, and the professional value of AWS certifications for IT students entering the workforce.

---

### 3. Key Takeaways & Career Development

* **Technical Insights**:
  * Learned how to dissect business requirements and balance trade-offs among high availability, scalability, and cost optimization from the Cloud Architect grand finale.
  * Gained a deeper DevSecOps mindset: security must be integrated continuously throughout the development lifecycle (Shift Left Security) rather than being treated as an afterthought.
  * Understood the value of Service-Oriented Monitoring in tracking user-facing metrics to ensure SLA commitments.
  * Obtained a clear framework and preparation strategies for the AWS Cloud Practitioner certification exam.

* **Practical Application**:
  * Observed the intense mini quiz competition between the two finalist teams to reinforce my own AWS knowledge, and networked with speakers and industry professionals after the event.
  * Will apply DevSecOps security practices to audit the AWS WAF rules protecting the API Gateway and CDN CloudFront distributions in the **ITCoach** project.
  * Will set up simple CloudWatch Metrics dashboards to monitor response latency of backend Lambda functions in the ITCoach system.
